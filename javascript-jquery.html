JavaScript + jQuery

Complete Reference & Concept Guide

ES2024 jQuery 3.7 Browser + Node.js

JavaScript is the language of the web — it makes pages interactive, fetches data, and now runs servers too. jQuery is its classic utility belt: a concise API for selecting elements, handling events, animating, and calling AJAX that tamed browser inconsistencies for over a decade.

Introduction

JavaScript vs jQuery

Everything jQuery does, vanilla JavaScript can do too — modern browsers adopted most of jQuery's best ideas (querySelectorAll, classList, fetch, forEach). jQuery remains everywhere in legacy codebases, WordPress themes, and quick prototypes, so reading and writing it is still a core skill.

Vanilla JS

The language itself. Zero dependencies, standards-based, runs everywhere.

jQuery

Concise DOM library: $() selection, chaining, events, effects, AJAX.

Node.js

The same language on the server: APIs, tooling, scripts, full-stack apps.

Rule of thumb — new greenfield code: learn and use vanilla JS (it is faster and dependency-free). Maintaining an existing site built on jQuery, or shipping a quick interaction-heavy page: jQuery is still perfectly fine and battle-tested.
Step 01 — Setup

Adding JS & jQuery to a Page

Scripts can be inline, embedded, or external. For anything beyond a few lines, use an external file loaded with defer — it keeps HTML clean and executes after the document is parsed.

Three ways to include JavaScript html
<!-- 1. Inline attribute (avoid for logic) -->
<button onclick="alert('Hi')">Greet</button>

<!-- 2. Embedded script block -->
<script>
  console.log('page loaded');
</script>

<!-- 3. External file â€” recommended -->
<!-- defer: download now, run after HTML parsing -->
<script src="app.js" defer></script>
Install jQuery via CDN html
<!-- Slim build omits AJAX/effects; use full for both -->
<script
  src="https://code.jquery.com/jquery-3.7.1.min.js"
  integrity="sha256-/JqT3SQfawRcv/BIHPThkBvs0OEvtFFmqPF/lYI/Cxo="
  crossorigin="anonymous"></script>

<!-- Your code AFTER jQuery, wrapped in ready -->
<script>
  $(function () {
    console.log('DOM ready, $ available:', $.fn.jquery);
  });
</script>
Script loading attributes reference
AttributeBehavior
(none)Blocks HTML parsing while the script downloads and runs

Where to place the tag? End of <body> or in <head> with defer. Both work; defer starts downloading earlier, so prefer it.
Step 02 — Core

Variables & Data Types

Use const by default, let when the value must change, and never var in new code (it is function-scoped and hoisted — a source of subtle bugs).

Declarations js
const name = 'Aarti';   // cannot be reassigned
let score = 0;           // can be reassigned
score += 10;

// const objects/arrays: contents CAN change,
// only the binding is fixed
const user = { name: 'Aarti' };
user.name = 'Ravi';       // fine
Template literals js
const items = 3;
const total = 199.5;

// Backticks: interpolation + multi-line
const summary = `
  Cart: ${items} item(s)
  Total: $${total.toFixed(2)}
`;

console.log(summary);

Classic gotcha: typeof null === 'object' (a bug kept for backwards compatibility) and 0.1 + 0.2 !== 0.3 (floating point). Compare floats with a tolerance: Math.abs(a - b) < Number.EPSILON.
Step 03 — Core

Functions

Functions are first-class values: store them in variables, pass them as arguments (callbacks), return them from other functions. Arrow functions are compact and inherit this from the surrounding scope.

Declaration vs arrow js
// Function declaration â€” hoisted
function add(a, b) {
  return a + b;
}

// Arrow function â€” concise, lexical this
const multiply = (a, b) => a * b;

// Default + rest parameters
function greet(name = 'guest', ...titles) {
  return `Hello ${titles.join(' ')} ${name}`;
}
Closure — private state js
function createCounter() {
  let count = 0;          // captured by inner fn

  return {
    increment: () => ++count,
    value:     () => count,
  };
}

const counter = createCounter();
counter.increment();
console.log(counter.value()); // 1
Closures power everything — event handlers that remember their element, module patterns, memoization, debounce/throttle utilities. If a function uses a variable defined outside it, that's a closure.
Step 04 — Core

Arrays & Objects

Reach for the transformation trio — map, filter, reduce — before writing any for loop. They return new arrays/values and chain beautifully.

map / filter / reduce js
const orders = [
  { id: 1, item: 'Keyboard', price: 1500, qty: 2 },
  { id: 2, item: 'Mouse',    price: 800,  qty: 1 },
  { id: 3, item: 'Monitor',  price: 9500, qty: 1 },
];

// map: transform each element
const labels = orders.map(o => o.item);

// filter: keep matches
const bigTickets = orders.filter(o => o.price > 1000);

// reduce: fold into one value
const revenue = orders.reduce(
  (sum, o) => sum + o.price * o.qty, 0
);

// chained pipeline
const cheapNames = orders
  .filter(o => o.price < 2000)
  .map(o => o.item.toLowerCase());
Destructuring & spread js
// Object destructuring + rename + default
const { item, price: cost = 0, tax = 0 } = orders[0];

// Array destructuring
const [first, , third] = ['a', 'b', 'c'];

// Spread: copy / merge (shallow)
const updated = { ...orders[0], qty: 5 };
const merged  = [...labels, 'Cable'];

// Rest: collect remaining args
const [head, ...tail] = labels;

Step 05 — Core

DOM Manipulation (Vanilla)

The DOM is a tree of nodes your script can read and rewrite. Select with CSS-style selectors, mutate text/classes/attributes, and build new nodes programmatically.

Selecting & reading js
// Single element (or null)
const form = document.querySelector('#signup');

// All matches (static NodeList)
document.querySelectorAll('.card')
  .forEach(card => card.classList.add('seen'));

// Read / write content
form.dataset.step;                 // data-step attr
form.textContent = 'safe text';    // no HTML parsing
// form.innerHTML = '<b>bold</b>'; // parses HTML â€” XSS risk with user input!
Creating & inserting js
const li = document.createElement('li');
li.className = 'list-group-item';
li.textContent = 'New task';

document.querySelector('#tasks').append(li);

// ClassList API
li.classList.add('done');
li.classList.toggle('selected');
li.classList.remove('seen');
li.classList.contains('done'); // true

li.remove(); // delete node
Batch DOM writes. Each write can trigger layout. Build fragments or set innerHTML once instead of appending inside a loop of hundreds of items.
Step 06 — Core

Events (Vanilla)

Attach listeners with addEventListener. The event object carries context (target, keys, coordinates) and lets you cancel default behavior.

Listeners & delegation js
const btn = document.querySelector('#save');

btn.addEventListener('click', (e) => {
  e.preventDefault();          // stop form submit / link nav
  console.log('clicked', e.target);
});

// Delegation: ONE listener handles many children,
// even ones added later
document.querySelector('#tasks').addEventListener('click', (e) => {
  const item = e.target.closest('li');
  if (item) item.classList.toggle('done');
});

// Keyboard + input
input.addEventListener('keydown', e => {
  if (e.key === 'Enter' && e.ctrlKey) save();
});

Step 07 — Async

Promises & async/await

JavaScript is single-threaded, so slow work (network, timers) is asynchronous. A Promise is a placeholder for a future value; async/await lets you write that flow in a straight line.

Promise basics js
function wait(ms) {
  return new Promise(resolve =>
    setTimeout(resolve, ms)
  );
}

wait(500)
  .then(() => console.log('half a second'))
  .catch(err => console.error(err))
  .finally(() => console.log('done'));

// Run in parallel, wait for all
const [a, b] = await Promise.all([
  fetch('/api/users'),
  fetch('/api/posts'),
]);
async / await js
async function loadDashboard() {
  try {
    const res = await fetch('/api/stats');

    // fetch does NOT throw on 404/500
    if (!res.ok) throw new Error(res.status);

    const stats = await res.json();
    render(stats);
  } catch (err) {
    console.error('load failed', err);
  }
}
Await sequentially only when required. await a(); await b(); takes the sum of both durations. If they are independent, start both then await Promise.all([a(), b()]) — total time becomes the slower one.
Step 08 — Async

Fetch API

fetch() is the modern HTTP client built into browsers: promise-based, streaming, and CORS-aware. Remember two rules — check res.ok, and body methods (json(), text()) are also async.

GET JSON js
async function getPosts() {
  const res = await fetch('/api/posts?page=1', {
    headers: { 'Accept': 'application/json' },
  });

  if (!res.ok) throw new Error(`HTTP ${res.status}`);
  return res.json();
}
POST JSON js
const res = await fetch('/api/posts', {
  method: 'POST',
  headers: {
    'Content-Type': 'application/json',
    'X-CSRF-TOKEN': token,   // Laravel etc.
  },
  body: JSON.stringify({
    title: 'Hello',
    body: 'First post',
  }),
});
Step 09 — jQuery

Selectors & Traversal

$() accepts any CSS selector and returns a jQuery object — an array-like wrapper with dozens of methods attached. Empty selections are safe: methods simply do nothing.

Selecting jquery
$('.card')             // by class
$('#signup')           // by id
$('ul li:first-child') // CSS selectors work
$('input[type="email"]')
$('tr:even')           // jQuery extras
$('div:not(.hidden)')
$('label:contains("Name")')

// Wrap DOM nodes / raw elements
$(document.activeElement);
$('<li>', { text: 'New', class: 'item' });
Traversal jquery
$('#item').parent()
             .parents('.panel')   // filtered ancestors
             .closest('form')      // nearest match
             .find('.error')       // descendants
             .children()
             .siblings('.active')
             .next().prev()
             .first().last()
             .eq(2);

// Iterate the wrapped set
$('.card').each(function (i) {
  console.log(i, $(this).data('id'));
});
Chaining works because setters return the same jQuery object. $('.box').addClass('on').fadeIn().text('Done'); reads top-to-bottom like a sentence.

Step 11 — jQuery

Events

One method to rule them all: .on(). Its second superpower is delegated events — bind to a stable ancestor, filter by a child selector, and future elements are handled automatically.

Binding jquery
// Ready shorthand
$(function () { /* DOM ready */ });

$('#save').on('click', function (e) {
  e.preventDefault();
  save();                    // this = raw DOM element
});

// Multiple events, one handler
$('#search').on('keyup focus blur', validate);

// Event data
$('.tab').on('click', { pane: '#main' }, open);
Delegation & cleanup jquery
// on(event, childSelector, handler)
// Works for rows added later via AJAX
$('#tasks').on('click', '.delete', function () {
  $(this).closest('li').fadeOut(function () {
    $(this).remove();
  });
});

$('#save').off('click');      // unbind
$('#save').trigger('click');  // fire manually

Step 12 — jQuery

Effects & Animation

jQuery ships toggleable show/hide, fade, and slide effects plus a generic .animate() for numeric CSS properties. All accept a duration and a completion callback.

Built-in effects jquery
$('#panel').show(300).hide(200).toggle();
$('#flash').fadeIn('slow').fadeOut(400).fadeToggle();
$('#drawer').slideDown().slideUp().slideToggle();
$('#row').fadeTo(200, 0.4);   // to opacity 0.4

// Callback after effect completes
$('#toast').fadeIn(200, function () {
  $(this).delay(1500).fadeOut();
});
Custom animation jquery
$('#card').animate({
  opacity: 0.9,
  left: '+=40px',      // relative moves
  height: 'toggle',    // smart keywords
}, 400, 'swing', function () {
  console.log('animation done');
});

// Queue control
$('#card').stop(true, true).fadeIn();
Durations: milliseconds or the strings "fast" (200ms) / "slow" (600ms). Respect users who prefer reduced motion — check matchMedia('(prefers-reduced-motion: reduce)') before animating.
Step 13 — jQuery

AJAX

jQuery made "fetch without reload" mainstream long before fetch() existed. $.ajax is the configurable core; $.get, $.post, $.getJSON and .load() are shortcuts over it.

$.ajax — full control jquery
$.ajax({
  url: '/api/posts',
  method: 'POST',
  data: { title: 'Hello', body: 'First post' },
  dataType: 'json',
  headers: { 'X-CSRF-TOKEN': token },
})
.done((data) => console.log('created', data))
.fail((xhr) => console.error(xhr.status, xhr.responseText))
.always(() => $('#spinner').hide());
Shorthands jquery
// GET expecting JSON
$.getJSON('/api/users', users => render(users));

// GET / POST with params
$.get('/api/search', { q: 'laravel' }, render);
$.post('/api/like', { id: 7 }, refreshCount);

// Inject server HTML straight into a node
$('#comments').load('/posts/1/comments');
Global settings jquery
// Defaults applied to every request
$.ajaxSetup({
  headers: { 'X-Requested-With': 'XMLHttpRequest' },
});

// Spinner during ANY ajax activity
$(document)
  .ajaxStart(() => $('#spinner').show())
  .ajaxStop(()  => $('#spinner').hide());
New code? Prefer fetch (or axios) — no dependency, native promises, better streaming. Reach for $.ajax when you're already in a jQuery codebase or need its mature global hooks (ajaxStart/ajaxStop) and JSONP support.
