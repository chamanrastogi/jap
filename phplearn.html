Leading Tips & Real-World Use Cases
Tip 1: Prefer str_contains() over strpos()
str_contains($haystack, $needle) (PHP 8.0+) returns a boolean â€” clearer intent, no risk of misinterpreting strpos() === 0 vs === false.
Tip 2: Use mb_* for UTF-8 safety
strlen() counts bytes, not characters. Use mb_strlen(), mb_substr(), mb_strpos() for multi-byte encodings (emoji, CJK, accented chars).
Tip 3: explode() + list() for parsing
list($name, $email) = explode(',', $line); â€” clean one-liner for CSV lines, config pairs, or delimiter-split data.
Tip 4: sprintf() for templates
sprintf('Hello %s, your ID is %04d', $name, $id); â€” cleaner than concatenation with built-in formatting.
Tip 5: URL & file checks with str_starts_with/str_ends_with
str_starts_with($url, 'https://') for protocol; str_ends_with($file, '.pdf') for extension â€” readable and fast.
Tip 6: Trim all user input
$input = trim($_POST['email']); â€” users paste extra whitespace. Combine with filter_var() for robust validation.

// Two Sum
function twoSum(array $nums, int $target): array {
    $map = [];
    foreach ($nums as $i => $num) {
        $diff = $target - $num;
        if (isset($map[$diff])) return [$map[$diff], $i];
        $map[$num] = $i;
    }
    return [];
}

// Binary search
function binarySearch(array $arr, int $target): int {
    $left = 0; $right = count($arr) - 1;
    while ($left <= $right) {
        $mid = intdiv($left + $right, 2);
        if ($arr[$mid] === $target) return $mid;
        if ($arr[$mid] < $target) $left = $mid + 1;
        else $right = $mid - 1;
    }
    return -1;
}

// Fibonacci (DP)
function fib(int $n): int {
    $dp = [0, 1];
    for ($i = 2; $i <= $n; $i++)
        $dp[$i] = $dp[$i-1] + $dp[$i-2];
    return $dp[$n];
}

1PHP Basics

Variables, types, operators, syntax.

echo can output multiple strings separated by commas and is slightly faster. print returns 1 and can be used in expressions. Both are language constructs.

isset() checks if a variable is declared and not null. empty() returns true for "", 0, "0", null, false, [], or unset variables.

== coerces types before comparing ("5" == 5 is true). === checks value and type ("5" === 5 is false). PHP 8.0+ made comparisons stricter (no longer treats 0 == "abc" as true).

define("NAME", value) runs at runtime and can be used anywhere. const NAME = value is compile-time and can be used inside classes. const is slightly faster. PHP 8.3 allows const with dynamic expressions.

8 types: string, int, float, bool, array, object, null, resource. PHP 8.2 added true/false as standalone types. Union types (int|string) and intersection types (Countable&Stringable) are also supported.

$x = $a ?? $b ?? 'default' returns first non-null. $data['key'] ??= 'default' (PHP 7.4+) assigns only if null. Both replace lengthy ternary + isset() patterns.

2Control Flow

Conditionals, loops, match.

foreach: iterate arrays/objects. for: known iteration count. while: unknown iterations, condition at start. do-while: guarantees at least one iteration.

match uses strict (===), returns a value, supports multiple conditions per arm (1, 2 => 'x'), throws UnhandledMatchError if no match. switch uses loose comparison, needs break, doesn't return a value.

Returns -1, 0, or 1. Used in usort callbacks: usort($arr, fn($a, $b) => $a <=> $b). Works with strings, numbers, arrays, and objects.

Uses : instead of { with endif/endfor/endforeach/endwhile. Useful in templates: <?php foreach($items as $item): ?> ... <?php endforeach; ?>

3Arrays

Indexed, associative, functions, spread.

array_unshift($arr, $v) / $arr[] = $v (or array_push) for adding. array_shift() / array_pop() for removing.

array_map applies callback, returns new array. array_filter filters by truthy callback. array_reduce reduces to single value. All are immutable.

Extracts a column from a 2D array. array_column($users, 'name') returns ['Alice', 'Bob']. Third param sets key column: array_column($users, 'name', 'id').

Unpacks arrays: $arr = [1, ...$middle, 4]. Works with Traversable objects (PHP 8.1+). Supports string keys (PHP 8.1+). Also used in function calls to unpack argument arrays.

array_key_exists('key', $arr) checks key existence (even if value is null). isset($arr['key']) returns false if value is null. Use array_key_exists when null vs missing matters.

4Strings

String manipulation, searching, formatting, tips.

str_contains($haystack, $needle) (PHP 8.0+) returns a boolean â€” cleaner for existence checks. strpos() returns the integer position or false if not found â€” requires strict !== false check. Always prefer str_contains() when you only need a yes/no answer.

trim($str) removes whitespace from both ends. ltrim()/rtrim() for left/right only. Critical for sanitizing user input â€” emails, usernames, and file paths often have accidental spaces from copy-paste.

function isSecure(string $url): bool {
    return str_starts_with($url, 'https://');
}
str_starts_with() (PHP 8.0+) is the most readable. Pre-8.0: strpos($url, 'https://') === 0. Also useful for file extensions (str_ends_with($file, '.pdf')).

Use mb_* functions: mb_strlen(), mb_substr(), mb_strpos(), mb_strtolower(). Set internal encoding: mb_internal_encoding('UTF-8'). strlen() counts bytes â€” a single emoji or CJK character can be 3-4 bytes, causing bugs in truncation and validation.

function isPalindrome(string $str): bool {
    $cleaned = preg_replace('/[^a-z0-9]/', '', strtolower($str));
    return $cleaned === strrev($cleaned);
}
Strips non-alphanumeric chars, lowercases, then compares with strrev(). Works for "A man, a plan, a canal: Panama". For multibyte: use mb_strtolower() and mb_strrev() (roll your own via preg_split()).

5Functions

User-defined, arrow, closures, scope.

Functions are standalone callables. Methods are functions inside a class with access to $this and visibility modifiers (public/private/protected).

Pass by parameter name: func(name: 'Alice', age: 30). Skip optional params. Named must come after positional. Breaks BC if param names change.

Arrow functions (fn($x) => $x*2) are single-expression, auto-capture by value. Closures use function + use() syntax, support multiple statements, can capture by reference (&$var).

Local, global, static scope. Globals need "global $var" or $GLOBALS['var'] inside functions. "static $count" persists between calls. Superglobals ($_GET, $_POST, etc.) are always accessible.

function factorial(int $n): int {
    return $n <= 1 ? 1 : $n * factorial($n - 1);
}
No, PHP does not optimize tail recursion. Deep recursion (>10k depth) causes stack overflow. Use iteration or trampolines.

6Object-Oriented Programming

Classes, inheritance, interfaces, traits, magic methods.

Define and initialize properties directly in the constructor: __construct(private string $name, public int $age). Eliminates separate property declarations.

Abstract classes can have implementations + properties; extends one only. Interfaces define contracts; implement many. PHP 8+ allows interface constants and abstract private methods.

Traits are reusable code blocks used via "use Loggable, Timestampable;". They solve the diamond problem, support abstract methods and properties. Conflict resolution via insteadof/as.

__construct (instantiation), __destruct (cleanup), __get/__set (dynamic props), __call/__callStatic (dynamic methods), __toString (string conversion), __invoke (callable object), __clone (deep copy), __debugInfo (var_dump), __serialize/__unserialize (PHP 7.4+).

Covariance: subclass method returns more specific type (Admin vs User). Contravariance: subclass method accepts less specific parameter (Animal vs Dog). Supported in PHP 7.4+.

7Advanced OOP

Namespaces, autoloading, readonly, anonymous classes.

Declared with "namespace App\Http;". Use via "use App\Http\Request;" or FQCN "\App\Http\Request". Support aliasing: "use ... as HttpRequest". Prevents name collisions.

PSR-4 maps namespace prefixes to directories. "App\\": "src/" means App\Http\Request loads from src/Http/Request.php. Composer generates vendor/autoload.php. Run "composer dump-autoload" to regenerate.

readonly properties (PHP 8.1) set once in constructor. readonly classes (PHP 8.2) make all properties readonly implicitly. Great for DTOs. Cannot combine with static or untyped properties.

PHP's generic empty class. Used when casting arrays to objects: (object) ['name' => 'Alice'] or json_decode() without the second argument.

For one-off implementations: new class extends Logger { ... }. Useful in tests (mocks), callbacks, or when a full class definition is overkill. Supports constructors and inheritance.

8MySQL & PDO

PDO, prepared statements, transactions.

PDO provides a consistent interface for MySQL, PostgreSQL, SQLite, etc. Supports prepared statements, named parameters, transactions, and multiple fetch modes. Safer and more portable than mysqli.

Query and data are sent separately. SQL template is compiled first; parameters are bound as data only. Even malicious input cannot alter query structure. Set PDO::ATTR_EMULATE_PREPARES to false for real prepared statements.

beginTransaction() â†’ execute queries â†’ commit()/rollBack(). Wrap in try/catch. Nested transactions not natively supported (use savepoints).

FETCH_ASSOC (column names), FETCH_NUM (numbered), FETCH_BOTH, FETCH_OBJ (object), FETCH_CLASS (class instance), FETCH_KEY_PAIR (key-value), FETCH_GROUP (grouped). Use ASSOC for general, CLASS for ORM.

Use JOINs or WHERE id IN (...) to batch-load relations. E.g., SELECT u.*, p.* FROM users u LEFT JOIN posts p ON p.user_id = u.id WHERE u.id IN (:ids).

9Security

XSS, SQL injection, CSRF, hashing.

Escape output with htmlspecialchars($data, ENT_QUOTES, 'UTF-8'). Use template engines that auto-escape. Set Content-Type header, X-Content-Type-Options, and CSP headers.

password_hash($pwd, PASSWORD_BCRYPT) creates 60-char hash with random salt. PASSWORD_ARGON2ID (PHP 7.3+) is more secure. Use password_verify() to check. Adjust cost: BCrypt=12, Argon2: memory=1024K.

CSRF tricks users into unwanted actions. Mitigate with: CSRF tokens in forms (bin2hex(random_bytes(32))), SameSite=Lax cookie attribute, custom AJAX headers, Origin/Referer checking.

function binarySearch(array $arr, int $target): int {
    $l = 0; $r = count($arr) - 1;
    while ($l <= $r) {
        $mid = intdiv($l + $r, 2);
        if ($arr[$mid] === $target) return $mid;
        if ($arr[$mid] < $target) $l = $mid + 1;
        else $r = $mid - 1;
    }
    return -1;
}

function twoSum(array $nums, int $target): array {
    $map = [];
    foreach ($nums as $i => $num) {
        $diff = $target - $num;
        if (isset($map[$diff])) return [$map[$diff], $i];
        $map[$num] = $i;
    }
    return [];
}
O(n) time complexity.

function fib(int $n): int {
    $dp = [0, 1];
    for ($i = 2; $i <= $n; $i++)
        $dp[$i] = $dp[$i-1] + $dp[$i-2];
    return $dp[$n];
}
O(n) time, O(n) space. Can optimize to O(1) space with two variables.

O(1) amortized. PHP arrays are hashtables internally. array_push (or $arr[] =) appends to the end with amortized O(1). array_unshift is O(n) because it reindexes.

14SOLID & Advanced

SOLID, PHPUnit, static analysis, async.

Single Responsibility Principle â€” a class should have one reason to change. Makes code easier to understand, test, and maintain. If a class does too much, split it into separate classes.

Open/Closed: open for extension, closed for modification. Example: instead of modifying a PaymentProcessor to add PayPal, create a PayPalPayment implements PaymentMethod. Add new methods without changing existing code.

Liskov Substitution: subtypes should replace their base types without breaking behavior. Violation: Square extends Rectangle â€” setting width on a Square also changes height, breaking Rectangle expectations.

Use a framework (Laravel/Symfony). Structure: src/ (PSR-4), tests/, public/, config/, routes/. Follow SOLID, use DI, repositories, services, and value objects. Automated CI with PHPUnit, PHPStan, PHP-CS-Fixer.

PHP-FPM handles concurrent requests via process pool. For high concurrency: use OPcache, async processing (Queues + workers), read replicas, connection pooling, HTTP caching (Varnish/CDN), horizontal scaling (multiple servers behind load balancer). Consider Swoole/ReactPHP for long-running async apps.
