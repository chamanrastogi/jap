PHP Basics

Variables, types, functions, arrays, strings, and PHP fundamentals.

PHP (Hypertext Preprocessor) is a widely-used open-source server-side scripting language designed for web development. It can be embedded into HTML and runs on the server, generating dynamic page content. PHP is loosely typed, interpreted, and supports object-oriented programming.

Variables in PHP start with a \$ sign followed by the name. They are loosely typed � no type declaration is required. Example: \ = "John";. PHP 7+ supports typed properties in classes and PHP 8+ adds union types.

echo can output multiple strings separated by commas and is slightly faster. print returns 1 so it can be used in expressions. Both are language constructs (not functions), so parentheses are optional.

PHP supports 8 primitive types: string, int, float, bool, array, object, null, and resource. PHP 8.2 added true and false as standalone types; PHP 8.3 added json validation functions.

isset() checks if a variable is declared and not null. empty() returns true when the variable is "", 0, "0", null, false, [], or an uninitialized variable. Both are language constructs, not functions.

Use define("NAME", value) or the const keyword (in classes and at compile-time). Constants are case-sensitive by convention uppercase, and cannot be changed once defined.

== (loose equality) coerces types before comparing, e.g. "5" == 5 is true. === (strict equality) checks both value and type, so "5" === 5 is false. Always prefer === for predictable comparisons.

Both include and evaluate a file. require throws a fatal error if the file is missing; include issues a warning and continues. Their _once variants (include_once, require_once) prevent the same file from being loaded more than once.

A session stores user data across multiple requests. Use session_start() to begin, then read/write via the \ superglobal. Sessions are file-based by default (or Redis/memcached in production), identified by a cookie (usually PHPSESSID).

Superglobals are built-in associative arrays accessible everywhere: \, \, \, \, \, \, \, \, and \. They have global scope regardless of context.

Use foreach (\ as \) or foreach (\ as \ => \). For indexed arrays, for (\ = 0; \ < count(\); \++) also works. PHP 8.4 introduced array_find(), array_any(), and array_all() helpers.

array_map(), array_filter(), array_reduce(), array_merge(), array_keys(), array_values(), in_array(), array_search(), sort(), array_unique(), array_chunk(), and array_column() (great with nested arrays from databases).

Type hints (type declarations) let you specify expected types for function arguments, return values, and class properties. PHP enforces them at runtime. Examples: function sum(int \, int \): int {}. PHP 8.0+ supports union types (string|int), mixed, and named arguments.

The nullsafe operator ?-> (PHP 8.0+) short-circuits method/property access when the left side is null. Instead of \ ? \->profile?->bio : null, you write \->profile?->bio. If \ is null, the whole expression returns null.

PHP 8.0+ attributes (annotations) add structured metadata to classes, methods, properties, etc. They use the #[Attribute] syntax. Attributes are read via reflection (\->getAttributes()). Laravel uses them for route definitions, event listeners, and model casting. Example: #[Route('get', '/dashboard')].

match (PHP 8.0+) is a strict, expression-based alternative to switch. It returns a value, doesn't require break, supports multiple conditions per arm, and throws UnhandledMatchError if no arm matches.

PHP 8.4 introduced property hooks (custom get/set logic for properties), asymmetric visibility (e.g., public get, private set), array_find(), array_any(), array_all() helpers, lazy objects without reflection, and improved HTML5 support in the DOM extension.

Both ensure the file is included at most once. require_once throws a fatal error if the file is missing; include_once issues a warning and continues.

Fibers (PHP 8.1+) are lightweight coroutines for cooperative multitasking. A fiber can be suspended (Fiber::suspend()) and resumed (\->resume()) from the main execution context.

Use try/catch for exceptions. Set a custom error handler via set_error_handler(). PHP 8.0+ converts many warnings into ErrorException (throwable). Use finally for cleanup code.

OOP in PHP

Classes, inheritance, interfaces, traits, and design patterns.

A class is a blueprint � it defines properties and methods. An object is an instance of a class created via new.

public � accessible everywhere. protected � within class and subclasses. private � within the declaring class only.

PHP 8.0+ constructor promotion: public function __construct(private int \, public string \) {}. Automatically creates and assigns properties.

A child class extends a parent using extends. PHP supports single inheritance. Use parent:: to call parent methods. Use final to prevent overriding.

An interface declares method signatures (contract). A class can implement multiple interfaces. An abstract class can provide partial implementation and properties; a class extends only one.

A trait enables code reuse in single-inheritance languages. A trait can contain methods and properties used via use TraitName in any class. Helps share behavior across unrelated classes.

static properties/methods belong to the class, not instances. Accessed via ClassName::\ or self::method(). Late static binding uses static:: for runtime resolution.

Late static binding uses static:: instead of self::. When called on a child class, static:: resolves to the child class at runtime, enabling polymorphic static calls.

DI is a pattern where an object receives its dependencies externally. Constructor injection passes dependencies via constructor params. Laravel's IoC container resolves dependencies automatically.

Single Responsibility, Open/Closed, Liskov Substitution, Interface Segregation, Dependency Inversion. Laravel's service container and contracts implement these extensively.

PHP magic methods start with __: __construct(), __destruct(), __call()/__callStatic(), __get()/__set(), __invoke(), __toString(), __clone(), __serialize()/__unserialize().

__invoke() lets an object be called as a function. Used in Laravel for invokable controllers, route actions, closures, and middleware.

\ = clone \ creates a shallow copy. __clone() is called after cloning for deep-copy behavior (e.g., cloning nested objects).

Repository separates data access from business logic. Repository classes encapsulate queries (find(), create(), paginate()). In Laravel, bound via service container for testability.

instanceof is an operator; is_a() is a function that accepts a class name string. Prefer instanceof for readability.

Strategy pattern defines interchangeable algorithms via an interface. Context accepts the strategy via constructor. Laravel uses this for mail drivers, cache backends, and filesystem disks.

Decorator wraps an object with the same interface, adding behavior dynamically. Laravel's middleware pipeline is a real-world decorator.

Observer defines a one-to-many dependency: when one object changes, all dependents are notified. Laravel's events and listeners implement this pattern.

PHP uses __call() and __callStatic() for dynamic method handling instead of traditional overloading. PHP 8.4 property hooks provide property access overloading.

PHP 8.3+ allows __clone() to modify readonly properties inside the clone method, enabling deep cloning of immutable objects.

Composer & Packages

Dependency management, autoloading, and packagist.

PHP's dependency manager. Reads composer.json, resolves dependencies, installs in vendor/. Provides PSR-4 autoloader.

Project manifest defining dependencies, autoloading rules, scripts, and metadata. Generated with composer init.

Records exact versions of all packages. Ensures consistent installs across environments. Commit to version control.

Maps namespaces to directories. App\Models\User maps to app/Models/User.php. Configured in composer.json under autoload.psr-4.

install reads lock file and installs exact versions. update resolves latest versions matching constraints and updates lock file.

Contains installed packages and autoload.php. Should not be committed (add to .gitignore).

Create directory with composer.json (name, type, require, autoload). Implement classes, push to GitHub, publish on Packagist.

Shell/PHP callables triggered by events (pre-install-cmd, post-update-cmd). Defined in composer.json under scripts.

dump-autoload regenerates autoloader files. -o generates classmap for PSR-0/4 classes, improving production performance.

Exact: 1.2.3. Tilde: ~1.2. Caret: ^1.2.3. Wildcard: 1.2.*. Pre-release: ^1.0@beta.

Laravel Basics

Installation, structure, service container, facades, and core concepts.

Open-source PHP framework by Taylor Otwell. MVC pattern, built-in ORM, Blade templating, routing, auth, queuing, testing. Current major version is Laravel 13.

CLI tool providing scaffolding commands (make:model, make:controller), database management (migrate), caching, and more.

app/ (Models, Controllers), config/, database/ (migrations), resources/ (views), routes/, storage/. Laravel 11+ has a leaner structure.

IoC container managing class dependencies. Auto-resolves classes, binds interfaces, registers singletons. Foundation of Laravel's bootstrapping.

Central bootstrapping mechanism. Register services, bindings, middleware in register() and boot() methods. Created with make:provider.

Static-like interface to container-bound classes. Cache::get() calls resolve('cache')->get(). Proxies backed by real container instances.

env() reads .env directly. config() reads cached config. Use config() in application code.

1. Request enters index.php 2. Autoloader 3. Service providers register/boot 4. Middleware pipeline 5. Route matched 6. Controller returns response 7. Response sent.

Version control for database schema. Each migration has up() and down(). Run with php artisan migrate.

Seeders populate test data. Factories generate fake model data with Faker.

REPL (interactive shell) for interacting with the Laravel app. Run Eloquent queries, test services, inspect config. Uses PsySH.

Simplified skeleton: fewer service providers, no separate kernels, bootstrap/app.php for config, routes/console.php merged, component-first approach.

Passes an object through pipes (middleware). Illuminate\Pipeline\Pipeline implements it. Used by middleware, queued job chain, mail sending.

Caches config, routes, events, and views. Run before production deploy. Use optimize:clear to revert.

Packages define extra.laravel.providers and aliases in composer.json. Laravel auto-registers them when Composer dumps autoload.

Add methods to core classes at runtime via Macroable trait. Example: Str::macro('partNumber', fn(...) => ...).

PHP built-in dev server on localhost:8000. For local development only.

Translation strings in lang/ files. Use __('messages.welcome'). Supports pluralization and locale detection.

Providers registered only when their services are first resolved, reducing request overhead. Implement DeferrableProvider.

-mcf creates model + migration + controller + factory in one command.

php artisan down returns 503. Bypass via --secret=token. Re-enable with php artisan up.

Routing & Controllers

Route definitions, middleware, named routes, controller methods, and subdomain routing.

Route::get('/url', [Controller::class, 'method']). Supports get, post, put, patch, delete, options.

Route::get('/profile', ...)->name('profile'). Generate URLs with route('profile', \).

Auto-injects models into controllers. Implicit: /users/{user} fetches by ID. Custom column: /users/{user:slug}.

Filters HTTP requests before the route handler. Examples: auth, throttle, verified, cors.

Route::prefix('admin')->middleware('auth')->group(function () { ... }).

Restricts requests per time window. Define limiters with RateLimiter::for(). Apply via throttle:api middleware.

resource creates 7 routes (includes create/edit views). apiResource creates 5 (RESTful only).

Route::domain('{account}.example.com')->group(...). Subdomain parameter passed to controller. Useful for multi-tenant apps.

Customize render() in exception handler. Create errors/404.blade.php. Use abort(404).

Route::bind('user', fn(\) => User::where('slug', \)->firstOrFail()) in AppServiceProvider.

HMAC-signed URLs: URL::signedRoute('unsubscribe', ['user' => 1]). Verify with \->hasValidSignature().

php artisan route:cache serializes routes for faster matching. Only works with closure-free controllers.

Blade & Views

Template engine, components, layouts, directives.

Laravel's templating engine. Uses .blade.php files, compiles to PHP, provides directives like @if, @foreach, @yield.

@yield('content') defines placeholder in layout. @section('content')...@endsection injects content in child view.

Generates hidden CSRF token field for POST forms. Laravel validates it via VerifyCsrfToken middleware.

Class-based components: make:component Alert creates PHP class + Blade template. Render: <x-alert />. Accept attributes, slots.

{{ \ }} auto-escapes via htmlspecialchars(). {!! \ !!} for raw output (caution with user content).

@push('scripts')...@endpush adds to stack. @stack('scripts') renders all pushed content in the layout.

Blade::directive('name', fn(\) => "<?php ... ?>") in service provider boot(). Returns raw PHP for compiled views.

@include('partials.header') includes a sub-view. @each('item', \, 'item', 'empty') renders per item.

Blade files in views/components/ without PHP class. Just create the file and use <x-name />.

Eloquent ORM

Models, relationships, scopes, accessors, mutators, and performance.

Laravel's Active Record ORM. Each model maps to a table, each instance to a row. Provides CRUD, relationships, scopes.

Snake-case plural tables (users), PK is id, FKs are user_id, pivot tables alphabetical (role_user).

hasOne, hasMany, belongsTo, belongsToMany, hasManyThrough, morphTo/morphMany, morphToMany.

Fetches related models upfront to avoid N+1 queries. User::with('posts.comments')->get().

Attribute::make(get: fn(\) => ..., set: fn(\) => ...). Transform attributes on retrieval/save.

Global scopes apply constraints to all queries. Local scopes are reusable query methods: scopePopular(\).

Lifecycle events: creating, created, updating, updated, saving, saved, deleting, deleted. Use Observers for complex logic.

Querying N items then accessing a relation per item causes N extra queries. Fix with eager loading (with()).

Use select(), eager loading, chunk() for large datasets, cursor() for memory-efficient iteration, DB indexes.

withCount('posts') adds posts_count without loading relation. Also: withSum(), withAvg().

A model belongs to multiple models on one association. Uses commentable_id and commentable_type. For comments, likes, tags.

User::paginate(15) returns items + pagination metadata. simplePaginate() skips total count. cursorPaginate() for offsetless.

Validation & Auth

Form validation rules, custom validators, authentication guards, and authorization.

\->validate([...]) in controllers. On failure, redirects back with errors or returns JSON.

Dedicated validation classes (make:request StoreUserRequest). Define rules() and authorize(). Type-hint in controller.

required, email, unique, exists, min/max, confirmed, file/image, regex, numeric.

Guards (session, token, sanctum) define auth method. Providers (Eloquent, database) retrieve users. Starter kits: Breeze, Jetstream.

API token auth for SPAs/mobile. Cookie-based for SPAs, tokens for API clients. Each token has abilities (scopes).

Gates: Closure-based auth checks. Policies: classes organizing auth logic per model. Use \->authorize() or @can.

make:rule Uppercase. Rule class implements ValidationRule with validate() method. Call \('msg') on failure.

Breeze: minimal scaffolding. Jetstream: teams, 2FA, API tokens. Fortify: headless auth backend.

confirmed rule expects password_confirmation field. Password::confirms() middleware for re-auth.

Password::min(8)->letters()->mixedCase()->numbers()->symbols()->uncompromised().

Add MustVerifyEmail to User model. Apply verified middleware. Laravel sends signed URL email.

API & Testing

API resources, routing, Postman alternative, PHPUnit, Pest.

Routes in routes/api.php. Return JSON: response()->json(['message' => 'OK'], 200).

make:resource UserResource. Transform Eloquent models to JSON. Define toArray() method.

Testing framework on PHPUnit with cleaner syntax. Uses closures: test('name', fn() => ...). Default in Laravel 13.

\->get('/api/users'), ->assertStatus(200), ->assertJsonStructure([...]). Use actingAs(\) for auth.

URL prefix (Route::prefix('v1')), header-based, or subdomain. Be consistent.

Dusk: browser automation with ChromeDriver. Sail: Docker dev environment (PHP, nginx, MySQL, Redis).

Default: 60 req/min for API. Custom with RateLimiter::for(). Apply throttle:10,1 middleware.

\->mock(Service::class) replaces real objects. shouldReceive()->once()->andReturn(true) for expectations.

Queues & Advanced

Jobs, queues, events, listeners, broadcasting, and caching.

Defer tasks via jobs: SendWelcomeEmail::dispatch(\). Workers: php artisan queue:work. Drivers: database, Redis, SQS.

Decoupled side effects. event(new UserRegistered(\)). Listeners can be queued via ShouldQueue.

Real-time WebSocket events via Laravel Reverb. Echo (JS) listens on frontend: Echo.channel('orders').

Cache::remember('key', \, fn() => ...). Drivers: file, Redis, Memcached, DynamoDB. Tags for grouping.

Serves app in memory via Swoole/RoadRunner. Boots once, handles many requests. Run php artisan octane:start.

Full-text search for Eloquent. Integrates with MeiliSearch, Algolia. Post::search('query')->get().

Job middleware wraps execution (e.g., rate limiting). Batching groups jobs: Bus::batch([...])->dispatch().

Multi-channel (mail, database, SMS, Slack). make:notification InvoicePaid. Send: \->notify().

Security & Deployment

CSRF, XSS, SQL injection, encryption, environment config, and deployment strategies.

Eloquent uses PDO parameter binding (auto-escaped). Raw queries use DB::select('...', [\]).

@csrf in forms. VerifyCsrfToken middleware validates on state-changing requests.

{{ }} escapes via htmlspecialchars(). Avoid {!! !!} with user input. Use CSP headers.

AES-256-CBC/GCM via Crypt::encrypt()/decrypt(). Uses APP_KEY. Authenticated encryption includes HMAC.

Never commit .env. Use .env.example template. Production: APP_DEBUG=false, APP_ENV=production.

composer install --no-dev, config:cache, route:cache, view:cache, migrations, permissions. Tools: Forge, Vapor, Envoyer.

Serverless deployment on AWS Lambda. Auto-scaling, SQS, S3, RDS. Single command deploy: vapor deploy.

Update deps, use HTTPS, validate input, escape output, set permissions, APP_DEBUG=false, optimize on deploy.

Coding Case Problems

Practical scenarios combining multiple concepts � design the solution, write the code, consider edge cases.

Models: Post, Category (hasMany posts), Tag (belongsToMany posts), Comment (polymorphic morphTo). Features: SoftDeletes on Post, Form Request validation, Policy for authorization, eager load relationships. Edge cases: Unauthorized access, empty tags, soft-deleted posts not visible.

Approach: Cart model with user_id (nullable), product_id, quantity. CartService: addItem(), removeItem(), getTotal(). Guests store in session. On login event, mergeCarts() upserts. Edge cases: Product deleted during session, duplicate items, quantity overflow.

Approach: UserRegistration model with JSON data column, current_step, completed. Validate step-by-step. Store session temp, persist on advance. Edge cases: Browser close mid-form, expired sessions, back button data loss.

Approach: Role (belongsToMany users), Permission (belongsToMany roles). Gate::define() with hasPermission(). Cache permissions. Middleware role:admin. Edge cases: Circular permissions, super admin bypass, cache invalidation.

Approach: Product::query()->when() for conditionals. Whitelist sort columns. API Resource collection for transformation. QueryString Form Request validation. Edge cases: Invalid sort field, SQL injection via sort, very large datasets.

Approach: SendBulkNotification job with tries=3, backoff=[5,10,30]. Notification::send() inside job. Log status in NotificationLog. Check cancelled_at flag. Edge cases: Email provider rate limits, large recipient lists, partial failures.

Approach: Intervention Image for resizing. S3 storage with CloudFront CDN. Queue resize jobs. Polymorphic media table. Validation: image|mimes:jpg,png,webp|max:2048. Edge cases: Malicious file upload, disk quota, CDN cache purge.

Approach: Message model (user_id, conversation_id, body). Broadcast MessageSent via ShouldBroadcast. Private channels with auth. Typing indicator on debounce. Unread count via conversation_user.last_read_at. Edge cases: Offline messages, concurrent connections, message ordering.

Approach: Route::domain('{tenant}.app.com'). Middleware resolves Tenant by subdomain, sets tenant_id. Global scope filters by tenant. Cache per-tenant config. Edge cases: Cross-tenant data leakage, subdomain takeover, DNS propagation.

Approach: Cashier/Stripe SDK. Checkout session creation. Webhook controller (CSRF exempt) handles checkout.session.completed, charge.refunded. Queue processing. Verify Stripe signature. Edge cases: Duplicate webhooks, expired sessions, refund race conditions.

Approach: Scout + Searchable trait on Product. toSearchableArray() includes category. Product::search('query')->where('category_id', 5)->paginate(). Configure filterable/sortable attributes. Queue indexing. Edge cases: Sync lag, typo-tolerance, empty results, re-indexing without downtime.
