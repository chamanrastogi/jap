ls — List Directory Contents

Complete reference for Linux, macOS, CMD and PowerShell 100+ examples POSIX Cross-platform

The ls command lists files and directories in the current or specified path. It is one of the most-used commands on Unix-like systems and is also available on Windows through PowerShell, WSL, or Git Bash. This guide covers every flag, output formats, sorting, filtering, CMD equivalents (dir), and practical recipes.

Introduction

What is ls?

ls (list) is a Unix/Linux command that displays the contents of a directory. It comes from the coreutils package on Linux and ships in nearly every Unix-like system, including macOS.

  • Type: External command
  • Package: coreutils (GNU) / BSD ls (macOS by default)
  • Manual: man ls · ls --help
  • Exit code: 0 on success, 1 on minor error, 2 on serious error
Where is it? — which ls → /bin/ls (Linux) · /usr/bin/ls (macOS) · available in WSL and Git Bash on Windows.
Quick Start — the 5 commands you'll use 90% of the time
ls                    # plain list
ls -l                # long format (permissions, owner, size, date)
ls -a                # include hidden files (dotfiles)
ls -lh               # long format + human-readable sizes
ls -la               # long + hidden → the "full" view

Basic Usage

Listing paths
ls                            # current directory
ls /usr/local/bin           # absolute path
ls ..                        # parent directory
ls ~                         # home directory
ls /etc /var /tmp           # multiple paths
ls -d /usr/*                # list directories inside /usr (not their contents)
Multiple paths in one command
ls src/ tests/ docs/
# src/:
  app.js  index.js  utils.js
# tests/:
  app.test.js  setup.js
# docs/:
  README.md  CHANGELOG.md

Output Formats

Two principal output shapes — short (default) and long (-l). There are also comma-separated, slashes-after-dirs, and classification modes.

Short format (default)
Documents  Downloads  Music  Pictures  Videos

Names separated by spaces, sorted alphabetically by default.

Long format -l
drwxr-xr-x  5 alice staff   160B Jun  4 10:14 Documents
-rw-r--r--  1 alice staff   1.2K Jun  4 09:30 notes.txt
lrwxr-xr-x  1 alice staff    32B Jun  1 08:00 link -> target

Permissions, links, owner, group, size, mtime, name.

Comma-separated -m
Documents, Downloads, Music, Pictures, Videos
One per line -1

Useful for piping into other tools.

Long Format — ls -l Decoded

The long format packs nine pieces of information on every line.

Sample line
-rw-r--r--  1 alice staff  1.2K  Jun  4 09:30  notes.txt
FieldExampleMeaning
1. Type--=file, d=dir, l=symlink, b=block, c=char, p=FIFO, s=socket
2. Permissionsrw-r--r--owner / group / other — r=4, w=2, x=1
3. Hard links1Number of hard links to the inode
4. OwneraliceUser name (or UID with -n)
5. GroupstaffGroup name (or GID with -n)
6. Size1.2KBytes · use -h for KB/MB/GB
7. MonthJunModification month
8. Day4Modification day of month
9. Time09:30HH:MM, or year if older than 6 months
10. Namenotes.txtFile or directory name
Pro tip: Use ls -lhF for the "default" long view most people want: long, human sizes, classify.

Hidden Files

On Unix, any file whose name starts with a dot (.) is hidden. ls skips them by default.

ls -a                  # show all, including . and ..
ls -A                  # show all, except . and ..
ls -la ~               # long listing of all home-dir entries
ls -d .[!.]*          # only hidden files (bash glob)
ls --hide='*.log'     # hide by pattern (no leading dot required)
ls -I '*.tmp'         # ignore pattern
Typical dotfiles
.bashrc        # login shell config
.bash_profile  # sourced at login
.zshrc         # zsh config (macOS default since Catalina)
.gitconfig     # git user/aliases
.ssh/          # SSH keys & known_hosts
.vscode/       # VS Code settings
.ENV / .env    # environment variables (never commit!)
.dockerignore  # files excluded from Docker context

Sorting

ls                       # alphabetical (default)
ls -r                   # reverse alphabetical
ls -t                   # newest first (mtime)
ls -tr                  # oldest first
ls -S                   # largest first
ls -Sr                  # smallest first
ls -X                   # by extension
ls -v                   # natural sort (file1, file2, file10)
ls -U                   # unsorted (directory order)
ls --sort=time         # same as -t
ls -l --time=birth     # sort by creation time (birth)
ls -l --time-style=full-iso   # 2026-06-04 09:30:42.000000000 +0530
ls -l --time-style=long-iso   # 2026-06-04 09:30
ls -l --time-style='+%Y-%m-%d %H:%M'  # strftime format
Tip: ls -ltr is the universal "show me the oldest files at the bottom" recipe used by sysadmins.

Recursive Listing

ls -R                   # recurse into subdirectories
ls -R src/             # recurse from a specific path
ls -Rl                 # long + recursive
ls -lR | less          # scroll long trees with a pager
ls -d $(find . -type d)  # list all directories only
tree                   # pretty tree (install via: apt install tree / brew install tree)
tree -L 2              # limit to 2 levels deep
tree -a -I 'node_modules|.git'  # ignore build/output dirs
Careful: ls -R / on a system with millions of files (think /var) may take a while. Pipe through less or filter with grep.

Filtering & Glob Patterns

Glob patterns are expanded by the shell, not by ls itself.

ls *.txt                 # all .txt files
ls file?.log            # file1.log, fileA.log (any single char)
ls file[0-9].log        # digits 0-9 only
ls [A-Z]*.md            # uppercase initial letter
ls **/*.js              # recursive (needs: shopt -s globstar in bash)
ls -I '*.min.js'         # ignore minified files
ls -d */                # only directories
ls -F | grep -v '/$'    # only files (non-dirs)
ls -1 | wc -l           # count entries
ls -lR | grep '^d'      # only directories (long format)
Glob cheat sheet
PatternMatches
*Any string (no slash)
?Any single char
[abc]Any one of a, b, c
[a-z]Any char in range a–z
[!abc]Any char except a, b, c
{a,b,c}Brace expansion (e.g. file.{js,ts})

PowerShell Equivalent

PowerShell on Windows includes ls and dir as built-in aliases for the Get-ChildItem cmdlet. For richer output, use Get-ChildItem directly.

ls                              # alias for Get-ChildItem
dir                             # also alias for Get-ChildItem
gci                             # shorter alias
Get-ChildItem                  # full cmdlet name
Get-ChildItem -Force           # like ls -a (include hidden)
Get-ChildItem -Recurse        # like ls -R
Get-ChildItem -File           # files only
Get-ChildItem -Directory      # directories only (like ls -d */)
Get-ChildItem *.txt           # filter by glob
ls | Sort-Object Length -Descending  # like ls -S
ls | Sort-Object LastWriteTime -Descending  # like ls -t
Get-ChildItem | Select Name,Length,LastWriteTime  # custom columns
ls | Where-Object { $_.Length -gt 1MB }  # filter by size
(Get-ChildItem).Count        # count files (like ls -1 | wc -l)
tree /F                        # pretty tree (built-in)
tree /F /A                     # tree with ASCII only (no Unicode lines)
PowerShell objects > text: ls in PowerShell returns objects with properties (Name, Length, LastWriteTime, Mode), not raw text. Pipe to Format-Table, Where-Object, Select-Object for powerful filtering — something the Unix ls cannot do on its own.
PowerShell: list the 5 largest files in a directory
Get-ChildItem -File -Recurse |
  Sort-Object Length -Descending |
  Select-Object -First 5 FullName, @{N='SizeMB';E={[math]::Round($_.Length/1MB,2)}}

WSL / Git Bash / MSYS

Three great ways to get real ls on Windows without leaving your machine:

WSL

Windows Subsystem for Linux. Full Linux ls with all flags.

wsl ls -la
wsl ls /mnt/c/Users

Access Windows files under /mnt/c/...

Git Bash

Bundled with Git for Windows. Includes coreutils.

ls -lah
ls -R --color=auto

Use the Git Bash Here context-menu.

MSYS2 / Cygwin

POSIX compatibility layer. Full Unix toolchain.

pacman -S coreutils
ls --color=auto

Heavier than Git Bash, more complete than WSL.

Recipes — Real-World Patterns

Find the 10 largest files anywhere under a path
find /var -type f -exec ls -lh {} + 2>/dev/null \
  | sort -k5 -h -r \
  | head -n 10

# One-liner (no find needed on most distros)
ls -lAR /var | sort -k5 -h -r | head
List every file modified in the last 24 hours
ls -lt --time-style=full-iso \
  | awk '$6 ~ /^'"$(date -u +%Y-%m-%d)"'/'

# Better: combine with find for accuracy
find . -type f -mtime -1 -exec ls -lh {} +
Count files by extension
ls -1 *.js 2>/dev/null | wc -l
ls -1 | sed 's/.*\.//' | sort | uniq -c | sort -rn

   42 js
   18 ts
   12 md
    5 json
List files with absolute paths
ls -d "$PWD"/*                       # current dir
ls -d "$PWD"/**/*(.)                # zsh globstar, files only
find "$(pwd)" -maxdepth 1 -mindepth 1  # portable
Watch a directory in real time (refresh every 2s)
watch -n 2 'ls -lh --color=auto'           # Linux
while true; do clear; ls -lh; sleep 2; done   # portable bash
Compare two directories (file names only)
diff <(ls -1 /etc) <(ls -1 /etc.old)

# Compare via contents
diff -rq /etc /etc.old
Find duplicate filenames across subdirectories
ls -R | awk '/:$/ {dir=$0; next} NF {print dir"/"$0}' \
  | awk -F/ '{print $NF}' \
  | sort | uniq -d
Show inode usage (find hard-linked duplicates)
ls -li | sort -n            # inodes ascending → duplicates cluster
find . -inum 1234567       # show all hard links to inode
Total size of current directory
ls -lAR | awk '/^total/ {sum += $1} END {print sum, "blocks"}'
du -sh .      # the more common way

Pro Tips & Tricks

1. The “show me everything” alias 
alias ll='ls -lahF'
alias la='ls -A'
alias l='ls -CF'

# Make it permanent (bash)
echo "alias ll='ls -lahF'" >> ~/.bashrc
source ~/.bashrc
2. Colorize even when piped (force it on) 
ls --color=always | less -R
ls -G | grep --color=never pattern   # grep on macOS, then strip
3. List only directories 
ls -d */                      # trailing slash trick
ls -l | grep '^d'             # long format filter
ls -d .*/ */ 2>/dev/null      # include hidden dirs
find . -maxdepth 1 -type d    # portable
4. ISO timestamps in long listing 
ls -l --time-style=long-iso
-rw-r--r-- 1 alice staff 1200 2026-06-04 09:30 notes.txt

ls -l --time-style=full-iso
-rw-r--r-- 1 alice staff 1200 2026-06-04 09:30:42.123456789 +0530 notes.txt
5. Numeric permissions (chmod-style) 
ls -l | awk '{print $1}' | tail -n +2

# rwxr-xr-x → 4+2+1  4+0+1  4+0+1 = 755
# rw-r--r-- → 4+2+0  4+0+0  4+0+0 = 644
# rwxrwxrwx → 777
stat -c '%a %n' *             # better tool
6. Group directories first 
ls --group-directories-first
ls -l --group-directories-first -F

# Make permanent
alias ls='ls --group-directories-first --color=auto'
7. Avoid the “Total N” header (use <kbd>G</kbd> in pager) 
ls -lh | tail -n +2            # skip the "total" line

# Or pipe to less and press G
ls -lh | less   $ then: press <G> to go to bottom
8. Quote names with spaces in scripts 
ls -Q                           # double-quote names
ls -1 | while read -r f; do
  echo "File: $f"
done

find . -maxdepth 1 -print0 | xargs -0 -I{} echo {}   # null-delimited (safest)
9. Block-size overrides 
ls -l --block-size=K     # always show KB
ls -l --block-size=M     # always show MB
ls -lh --si             # powers of 1000 (kB, MB, GB)
10. Production-safe defaults (for scripts) 
ls -1 --color=never          # one per line, no escape codes
LC_ALL=C ls -1              # locale-independent sort
ls --quoting-style=literal  # no quotes, no escapes

Common Errors & Fixes

Error messageCause & fix
ls: cannot access 'foo': No such file or directory Path doesn't exist. Check spelling or use tab-completion. The directory may have been moved or deleted.
ls: cannot open directory 'foo': Permission denied You lack read (r) permission. Fix with sudo chmod +r foo or run as a user with access.
ls: invalid option -- 'X' You're probably on BSD/macOS ls where some GNU flags differ. Run man ls for the local man page.
Coloured output corrupts in pipe ANSI codes are leaking. Use ls --color=never or pipe through sed 's/\x1b\[[0-9;]*m//g'.
Spaces in filenames break for f in $(ls) Never use for f in $(ls). Use find . -maxdepth 1 -print0 | while IFS= read -r -d '' f; do ... done or while read f; do ... done < <(ls -1).
Newlines in filenames break scripts Use find -print0 + xargs -0 or while read -d ''. ls itself handles them, but downstream tools may not.
ls: .: Operation not permitted (macOS) macOS Catalina+ enforces Path Randomization in some apps. ls itself is unaffected — check whether you're inside a sandboxed app's data container.
Symbolic link loops ls -L follows links, can infinite-loop. Use ls -l (don't follow) and look at the -> target arrow.
Sorting different on Linux vs macOS macOS uses BSD ls which sorts case-insensitively by default. Force POSIX sort: LC_ALL=C ls.
