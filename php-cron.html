2. nohup & Background Processing

For long-running scripts that must survive SSH disconnection, use nohup or PHP's process control.

Using nohup

nohup /usr/bin/php /app/processor.php > /var/log/processor.log 2>&1 &
echo $! > /var/run/processor.pid

Using & (Background)

/usr/bin/php /app/processor.php &
# Capture PID
PID=$!
echo $PID > /tmp/processor.pid

PHP Process Control

<?php
// Fork a child process
$pid = pcntl_fork();
if ($pid == -1) { die('Could not fork'); }
elseif ($pid) {
    // Parent process
    pcntl_wait($status);
} else {
    // Child process - do work
    processData();
    exit(0);
}

4. Common Patterns

Command-Line Arguments

<?php
// Parse CLI arguments
$options = getopt('', ['type:', 'limit:', 'dry-run', 'from-id:']);
$type = $options['type'] ?? 'default';
$limit = isset($options['limit']) ? (int)$options['limit'] : 1000;
$dryRun = isset($options['dry-run']);
echo "Processing $limit records of type $type\n";

Reading from STDIN

<?php
// Pipe data via STDIN
$data = stream_get_contents(STDIN);
$lines = explode("\n", trim($data));
foreach ($lines as $line) {
    processLine(trim($line));
}

Exit Codes

<?php
// 0 = success, 1 = error
fwrite(STDOUT, "Processing complete\n");
exit(0);

// On failure:
fwrite(STDERR, "Processing failed\n");
exit(1);

5. Memory Management

PHP scripts processing large datasets must carefully manage memory to avoid exhaustion.

Memory Limits

<?php
// Check current limit
echo ini_get('memory_limit') . "\n";

// Set for this script
ini_set('memory_limit', '2048M');

// Monitor usage
echo memory_get_usage(true) . " bytes\n";
echo memory_get_peak_usage(true) . " bytes peak\n";

Garbage Collection

<?php
// Force garbage collection
$cycles = gc_collect_cycles();
echo "Collected $cycles cycles\n";

// Enable cyclic GC
gc_enable();

Chunk Processing

<?php
$allIds = range(1, 1000000);
$chunkSize = 1000;
foreach (array_chunk($allIds, $chunkSize) as $chunk) {
    processChunk($chunk);
    unset($chunk);
    gc_collect_cycles();
}

6. Scaling to Millions

Generator Pattern

<?php
function getRecords(PDO $pdo, int $chunkSize = 1000): Generator {
    $lastId = 0;
    while (true) {
        $stmt = $pdo->prepare("SELECT * FROM large_table WHERE id > ? ORDER BY id LIMIT ?");
        $stmt->execute([$lastId, $chunkSize]);
        $rows = $stmt->fetchAll();
        if (empty($rows)) break;
        foreach ($rows as $row) yield $row;
        $lastId = (int)end($rows)['id'];
        unset($rows);
    }
}

foreach (getRecords($pdo) as $record) {
    processOne($record);
}

Batch Updates with CASE

<?php
// Single query for multiple updates
$cases = [];
foreach ($records as $r) {
    $cases[] = "WHEN id = {$r['id']} THEN {$r['status']}";
}
$sql = "UPDATE large_table SET status = CASE " . implode(' ', $cases) . " ELSE status END";
$pdo->exec($sql);

7. MySQL & Keyset Pagination

Keyset pagination (also called "seek method") is dramatically faster than LIMIT/OFFSET for large offsets.

BAD: LIMIT/OFFSET (slow for large offsets)

<?php
$page = 1;
$perPage = 1000;
$offset = ($page - 1) * $perPage;
$stmt = $pdo->prepare("SELECT * FROM large_table ORDER BY id LIMIT ? OFFSET ?");
$stmt->execute([$perPage, $offset]);

GOOD: Keyset Pagination (fast)

<?php
$lastId = 0;
$perPage = 1000;
while (true) {
    $stmt = $pdo->prepare("SELECT * FROM large_table WHERE id > ? ORDER BY id LIMIT ?");
    $stmt->execute([$lastId, $perPage]);
    $rows = $stmt->fetchAll();
    if (empty($rows)) break;
    foreach ($rows as $row) processRow($row);
    $lastId = (int)end($rows)['id'];
    unset($rows);
}
Note: Keyset pagination requires a unique, sequential key (like an auto-increment id). For non-sequential keys, use a cursor-based approach.

JSON logging for structured, parseable output.

class BatchLogger {

    public function __construct(string $logFile = 'php://stdout') {
        $this->logFile = $logFile;

    }

$log->log('JOB_START', ['pid' => getmypid()]);

10. Prevent Duplicate Execution

Use flock to prevent overlapping cron job executions.

<?php
$lockFile = '/tmp/processor.lock';
$handle = fopen($lockFile, 'c');
if (!flock($handle, LOCK_EX | LOCK_NB)) {
    fwrite(STDOUT, "Already running. Exiting.\n");
    exit(0);
}
processRecords();
flock($handle, LOCK_UN);
fclose($handle);
unlink($lockFile);

13. Troubleshooting

Script Exits Immediately
Fix: php -l script.php (syntax), php script.php (see errors), use full PHP path.
Memory Exhausted
Fix: Chunk reads, unset vars, gc_collect_cycles(), or php -d memory_limit=4G.
MySQL Gone Away
Fix: Reconnect logic, increase wait_timeout and max_allowed_packet.
Duplicate Executions
Fix: flock-based locking (Section 10).
Wrong PHP Version
Fix: /usr/bin/php8.3 /app/script.php
Permission Denied
Fix: chmod +x script.php, ensure cron user owns files.
Cron Not Running
Fix: systemctl status cron, check /var/log/syslog, test with * * * * * echo test >> /tmp/test.log
High CPU / Infinite Loops
Fix: usleep(100000), nice -n 19, iteration limits, runtime timeouts.

15. Complete Enterprise Example

A fully documented, production-ready script incorporating every concept from this guide:

  • CLI argument parsing
  • flock process locking
  • Chunked reads (keyset pagination)
  • Batch inserts/updates with transactions
  • JSON structured logging
  • Progress tracking with rate
  • Memory monitoring
  • Graceful shutdown (SIGTERM)
  • Resume after failure
  • Retry with exponential backoff
  • Timeout protection
  • Exit codes for cron
<?php
/**
 * Enterprise Batch Processor
 *
 * Usage:
 *   php batch_processor.php                           # Run normally
 *   php batch_processor.php --resume                   # Resume checkpoint
 *   php batch_processor.php --chunk=2000 --batch=500   # Custom sizes
 *   php batch_processor.php --from-id=100000           # Start at ID
 *   php batch_processor.php --max-time=3600             # Max runtime
 *   php batch_processor.php --dry-run                   # Preview only
 *
 * Cron (5 min intervals, auto-resume):
 *   */5 * * * * /usr/bin/php /app/batch_processor.php --resume --max-time=270
 */

declare(strict_types=1);

// ---- Config ----
$config = [
    'db' => [
        'host'     => getenv('DB_HOST')     ?: 'localhost',
        'dbname'   => getenv('DB_NAME')     ?: 'production',
        'user'     => getenv('DB_USER')     ?: 'app',
        'password' => getenv('DB_PASSWORD') ?: '',
        'charset'  => 'utf8mb4',
    ],
    'chunk'      => 1000,
    'batch'      => 500,
    'resume'     => false,
    'fromId'     => 0,
    'maxRuntime' => 0,
    'dryRun'     => false,
    'lockFile'   => '/tmp/batch_processor.lock',
    'stateFile'  => '/tmp/batch_processor_state.json',
    'logFile'    => '/var/log/batch_processor.log',
];

// ---- CLI Args ----
$opts = getopt('', ['resume','chunk:','batch:','from-id:','max-time:','dry-run']);
foreach (['resume'=>'resume','chunk'=>'chunk','batch'=>'batch','from-id'=>'fromId','max-time'=>'maxRuntime','dry-run'=>'dryRun'] as $k => $p) {
    if (isset($opts[$k])) $config[$p] = $k === 'dry-run' ? true : (is_string($opts[$k]) ? (int)$opts[$k] : true);
}

// ---- Init ----
$startTime = microtime(true);
$pid = getmypid();
$logger = new JsonLogger($config['logFile']);
$totalProcessed = 0;
$totalErrors = 0;
$shutdownRequested = false;

pcntl_signal(SIGTERM, function () use (&$shutdownRequested) { $shutdownRequested = true; });
pcntl_signal(SIGINT,  function () use (&$shutdownRequested) { $shutdownRequested = true; });

// ---- Process Lock ----
$lock = new ProcessLock($config['lockFile']);
if (!$lock->acquire()) { $logger->warn('Already running'); exit(0); }

// ---- DB ----
try {
    $pdo = new PDO(
        "mysql:host={$config['db']['host']};dbname={$config['db']['dbname']};charset={$config['db']['charset']}",
        $config['db']['user'], $config['db']['password'],
        [PDO::ATTR_ERRMODE => PDO::ERRMODE_EXCEPTION, PDO::ATTR_DEFAULT_FETCH_MODE => PDO::FETCH_ASSOC]
    );
} catch (PDOException $e) { $logger->error('DB failed', ['error' => $e->getMessage()]); $lock->release(); exit(1); }

// ---- Resume ----
$startId = $config['fromId'];
if ($config['resume'] && $startId === 0) {
    $state = file_exists($config['stateFile']) ? json_decode(file_get_contents($config['stateFile']), true) : null;
    if ($state) { $startId = $state['last_id']; $logger->info('Resuming', $state); }
}

// ---- Main Loop ----
$logger->info('Job started', ['pid' => $pid, 'config' => $config]);
$chunkNumber = 0;
$lastId = $startId;

while (true) {
    if ($shutdownRequested) { $logger->warn('Shutdown signal received'); break; }
    $elapsed = microtime(true) - $startTime;
    if ($config['maxRuntime'] > 0 && $elapsed >= $config['maxRuntime']) { $logger->warn('Runtime limit'); break; }

    $chunkNumber++;
    $batchStart = microtime(true);

    // Read chunk
    try {
        $stmt = $pdo->prepare('SELECT * FROM source_table WHERE id > ? ORDER BY id LIMIT ?');
        $stmt->execute([$lastId, $config['chunk']]);
        $rows = $stmt->fetchAll();
    } catch (PDOException $e) {
        $logger->error('Query failed', ['id' => $lastId, 'error' => $e->getMessage()]);
        sleep(5); continue;
    }
    if (empty($rows)) { $logger->info('No more records'); break; }

    // Transform
    $insertBatch = $updateBatch = [];
    foreach ($rows as $row) {
        try {
            $r = transform($row);
            if ($r['_action'] === 'insert') { unset($r['_action']); $insertBatch[] = $r; }
            else { unset($r['_action']); $updateBatch[] = $r; }
        } catch (Exception $e) {
            $totalErrors++;
            $logger->error('Transform failed', ['id' => $row['id'] ?? '?', 'error' => $e->getMessage()]);
        }
    }

    // Batch ops
    if (!empty($insertBatch) && !$config['dryRun']) batchInsertWithRetry($pdo, $insertBatch, $config['batch'], $logger);
    if (!empty($updateBatch) && !$config['dryRun']) batchUpdateWithRetry($pdo, $updateBatch, $config['batch'], $logger);

    // Progress
    $totalProcessed += count($rows);
    $lastId = (int)end($rows)['id'];
    if (!$config['dryRun']) saveState($config['stateFile'], ['last_id' => $lastId, 'total_processed' => $totalProcessed, 'total_errors' => $totalErrors, 'timestamp' => time()]);

    $logger->info('Batch', [
        'chunk' => $chunkNumber, 'records' => count($rows),
        'inserted' => count($insertBatch), 'updated' => count($updateBatch),
        'total' => $totalProcessed, 'errors' => $totalErrors,
        'time_ms' => round((microtime(true)-$batchStart)*1000),
        'mem' => formatBytes(memory_get_usage(true)),
        'peak' => formatBytes(memory_get_peak_usage(true)),
        'last_id' => $lastId,
    ]);

    unset($rows, $insertBatch, $updateBatch);
    gc_collect_cycles();

    // Memory safety
    $limit = returnBytes(ini_get('memory_limit'));
    if ($limit > 0 && memory_get_usage(true) > $limit * 0.85) {
        $logger->error('Critical memory', ['usage' => formatBytes(memory_get_usage(true))]);
        break;
    }
}

// ---- Summary ----
$elapsed = microtime(true) - $startTime;
$logger->info('Job finished', [
    'processed' => $totalProcessed, 'errors' => $totalErrors,
    'elapsed' => gmdate('H:i:s', $elapsed),
    'peak_mem' => formatBytes(memory_get_peak_usage(true)),
]);
$lock->release();
@unlink($config['stateFile']);
echo "DONE: $totalProcessed processed, $totalErrors errors\n";
exit($totalErrors > 0 ? 1 : 0);

// ---- Helpers ----

function transform(array $row): array {
    return [
        'source_id' => (int)$row['id'], 'name' => mb_strtoupper($row['name'] ?? ''),
        'email' => mb_strtolower(trim($row['email'] ?? '')), 'amount' => (float)($row['amount'] ?? 0),
        'is_active' => ($row['status'] === 'active') ? 1 : 0, 'processed_at' => date('Y-m-d H:i:s'),
        '_action' => ($row['exists_in_dest'] ?? false) ? 'update' : 'insert',
    ];
}

function batchInsertWithRetry(PDO $pdo, array $rows, int $bs, JsonLogger $log): bool {
    foreach (array_chunk($rows, $bs) as $chunk) {
        for ($a = 1; $a <= 3; $a++) {
            try {
                $pdo->beginTransaction();
                $cols = implode(',', array_keys($chunk[0]));
                $vals = []; $params = [];
                foreach ($chunk as $r) {
                    $vals[] = '(' . implode(',', array_fill(0, count($r), '?')) . ')';
                    $params = array_merge($params, array_values($r));
                }
                $pdo->prepare("INSERT INTO dest_table ($cols) VALUES " . implode(',', $vals))->execute($params);
                $pdo->commit();
                break;
            } catch (Exception $e) {
                $pdo->rollBack();
                $log->error("Insert attempt $a failed", ['error' => $e->getMessage()]);
                if ($a < 3) sleep(pow(2, $a)); else return false;
            }
        }
    }
    return true;
}

function batchUpdateWithRetry(PDO $pdo, array $rows, int $bs, JsonLogger $log): bool {
    foreach (array_chunk($rows, $bs) as $chunk) {
        for ($a = 1; $a <= 3; $a++) {
            try {
                $pdo->beginTransaction();
                $s = $pdo->prepare('UPDATE dest_table SET name=?,email=?,amount=?,is_active=?,processed_at=? WHERE source_id=?');
                foreach ($chunk as $r) $s->execute([$r['name'],$r['email'],$r['amount'],$r['is_active'],$r['processed_at'],$r['source_id']]);
                $pdo->commit(); break;
            } catch (Exception $e) {
                $pdo->rollBack();
                $log->error("Update attempt $a failed", ['error' => $e->getMessage()]);
                if ($a < 3) sleep(pow(2, $a)); else return false;
            }
        }
    }
    return true;
}

class ProcessLock {
    private $h = null; private string $f;
    public function __construct(string $f) { $this->f = $f; }
    public function acquire(): bool {
        $this->h = fopen($this->f, 'c');
        if (!$this->h) return false;
        if (!flock($this->h, LOCK_EX|LOCK_NB)) { fclose($this->h); $this->h = null; return false; }
        ftruncate($this->h, 0); fwrite($this->h, (string)getmypid()); fflush($this->h);
        return true;
    }
    public function release(): void {
        if ($this->h) { flock($this->h, LOCK_UN); fclose($this->h); $this->h = null; }
        @unlink($this->f);
    }
    public function __destruct() { $this->release(); }
}

class JsonLogger {
    private string $f;
    public function __construct(string $f) { $this->f = $f; $d = dirname($f); if (!is_dir($d)) mkdir($d, 0755, true); }
    public function info(string $m, array $c = []) { $this->w('INFO', $m, $c); }
    public function warn(string $m, array $c = []) { $this->w('WARN', $m, $c); }
    public function error(string $m, array $c = []) { $this->w('ERROR', $m, $c); }
    private function w(string $l, string $m, array $c): void {
        $e = json_encode(['time'=>date('c'),'level'=>$l,'pid'=>getmypid(),'message'=>$m,'context'=>$c], JSON_UNESCAPED_SLASHES);
        file_put_contents($this->f, $e."\n", FILE_APPEND|LOCK_EX);
        fwrite(STDOUT, $e."\n");
    }
}

function readState(string $f): ?array { return file_exists($f) ? json_decode(file_get_contents($f), true) : null; }
function saveState(string $f, array $s): void { file_put_contents($f, json_encode($s), LOCK_EX); }
function formatBytes(int $b): string { $u=['B','KB','MB','GB']; $i=0; while($b>=1024&&$i<3){$b/=1024;$i++;} return round($b,2).' '.$u[$i]; }
function returnBytes(string $v): int {
    $v=trim($v); if($v==='-1') return -1;
    $l=strtolower($v[-1]); $n=(int)substr($v,0,-1);
    return match($l) { 'g'=>$n*1024**3, 'm'=>$n*1024**2, 'k'=>$n*1024, default=>(int)$v };
}
