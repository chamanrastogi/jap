Local AI Coding Assistant Complete Roadmap for PHP / Laravel Developers

This guide walks you through setting up a fully local AI coding assistant on your Windows machine — with autocomplete, chat, and full project generation — no cloud API keys, no subscriptions, no data leaving your PC. All tools are free and open-source.

Overview

A local AI coding assistant runs a Large Language Model (LLM) on your own machine. Tools like Ollama (to run models) + Continue.dev (VS Code extension) give you the same experience as GitHub Copilot — but completely offline.

100% Private

Your code never leaves your machine. No data sent to any server.

Unlimited Usage

No rate limits, no token costs, no subscription fees.

Works Offline

No internet needed after the initial model download.

Hardware Requirements

What you need depends on which model you run. Here are the tiers:

Tier RAM VRAM (GPU) Storage Best For
Minimum 8 GB — (CPU only) 10 GB free Small models (Phi-3, Qwen 1.5B) — basic autocomplete
Recommended 16 GB 4 GB (GTX 1650+) 20 GB free Mid models (CodeGemma 7B, DeepSeek-Coder 6.7B) — good autocomplete + chat
Ideal 32 GB 8 GB (RTX 3060+) 40 GB free Large models (Llama 3.1 8B, DeepSeek-Coder 33B) — best code generation
Windows Note: Ollama works natively on Windows. If you don't have a good GPU, it falls back to CPU automatically — slower but works. For GPU acceleration on Windows, you need NVIDIA CUDA or AMD ROCm.

Step 1: Install Ollama

Ollama is the easiest way to run LLMs locally. It wraps llama.cpp under the hood and exposes a simple REST API.

Installation

1. Download
Go to ollama.com/download and download the Windows installer.
2. Install
Run the installer. Ollama runs as a system tray app and starts automatically on boot.
3. Verify
Open PowerShell and run:
ollama --version
4. Test API
Ollama API runs at http://localhost:11434. Check:
curl http://localhost:11434
Ollama API is OpenAI-compatible. This means any tool that works with OpenAI (like Continue.dev) can point to http://localhost:11434/v1 and use local models instead.

Step 2: Pull a Coding Model

Ollama lets you download models with a single command. Here are the best models for PHP/Laravel coding:

DeepSeek-Coder 6.7B

Best overall for PHP/Laravel. Strong code completion, understands modern PHP syntax well.

RECOMMENDED
ollama pull deepseek-coder:6.7b
~4 GB download, runs on 8 GB RAM / 4 GB VRAM
CodeGemma 2B / 7B

Google's code model. 2B is very fast for autocomplete, 7B is better for chat. Decent PHP support.

GOOD
ollama pull codegemma:2b    # fast + light (2B)
ollama pull codegemma:7b    # smarter (7B)
2B: 1.6 GB | 7B: 4.5 GB
CodeQwen 1.5 7B

Alibaba's code model. Very strong at code completion, supports 30+ languages including PHP. Good for Laravel.

GOOD
ollama pull qwen2.5-coder:7b
~4.5 GB download
Llama 3.1 8B

Meta's general-purpose model. Not code-specialized but very capable. Great for chat and explaining concepts.

VERSATILE
ollama pull llama3.1:8b
~4.7 GB download
PHP-specific tip: DeepSeek-Coder 6.7B and CodeQwen 7B produce the most accurate Laravel code. Start with deepseek-coder:6.7b — it's the sweet spot between quality and speed.

Verify a Model Works

After pulling, test it in the terminal:

ollama run deepseek-coder:6.7b "Write a Laravel controller for a blog post CRUD"

Press Ctrl+D to exit the chat.

Step 3: VS Code + Continue.dev

Continue.dev is a free, open-source AI code assistant that connects to any LLM backend, including Ollama. It works as a VS Code extension.

Why Continue.dev? It's the only free, local-first AI coding assistant that supports both autocomplete (inline suggestions as you type) and chat (ask questions about your code). Alternatives: Tabby (self-hosted), Cody (Sourcegraph), Codeium. Continue is the most popular and best for local setups.

Setup

  • Open VS Code → Extensions panel (Ctrl+Shift+X)
  • Search "Continue" → Install (by Continue.dev, blue icon)
  • After install, click the Continue icon in the left sidebar
  • Click the gear icon → "Open config"

    • This opens ~\.continue\config.json. Replace the contents with:

    {
  "models": [
    {
      "title": "DeepSeek-Coder",
      "provider": "ollama",
      "model": "deepseek-coder:6.7b"
    }
  ],
  "tabAutocompleteModel": {
    "title": "DeepSeek-Coder",
    "provider": "ollama",
    "model": "deepseek-coder:6.7b"
  }
}

    TIP For faster autocomplete, use a smaller model like codegemma:2b for the tabAutocompleteModel and keep the larger model for chat.

    Step 4: Enable Autocomplete

    With the config above, Continue.dev automatically provides tab autocomplete — inline gray suggestions as you type PHP code.

    How it works
    1. Start typing PHP code in your editor
    2. After a brief pause, Continue sends the context to Ollama
    3. A gray ghost text appears suggesting the next lines
    4. Press Tab to accept, or keep typing to ignore
    Speed Tuning

    If autocomplete is slow, try:
    - Use a smaller model (CodeGemma 2B)
    - Enable GPU acceleration in Ollama
    - Reduce context length in config: 

    "tabAutocompleteModel": {
  "provider": "ollama",
  "model": "codegemma:2b",
  "contextLength": 1024
}
    Pro Tip for Laravel: Continue.dev learns from your open files. If you're editing a UserController with User.php open nearby, it understands the model relationships and suggests correct Eloquent queries.

    Step 5: AI Chat in Editor

    Beyond autocomplete, you can chat with the AI about your code. Open Continue's panel (click the Continue icon in the sidebar) and ask questions:

    Code Questions
    • "Explain this Laravel service provider"
    • "How do I implement a repository pattern here?"
    • "Fix this N+1 query issue in Eloquent"
    • "Write a FormRequest validation for this controller"
    Refactoring & Generation
    • "Refactor this controller to use actions"
    • "Generate a migration for a products table"
    • "Create a notification for order status change"
    • "Write a PHPUnit test for this service"

    Using Code Context

    In the Continue chat panel, you can highlight code in the editor and press Ctrl+L to add it to the chat context. The AI sees your current file, selection, and can also read other open files to give better answers. 

    // Quick shortcuts:
Ctrl+I  → Inline chat (opens a dialog in the editor)
Ctrl+L  → Add selected code to chat context
Ctrl+Shift+L → Ask about selected code directly

    Step 6: Generate a Laravel App

    You can use Continue's chat to generate entire Laravel features — or even scaffold a whole project. Here's the workflow:

    Scaffold a New Laravel Project

  • In terminal: composer create-project laravel/laravel myapp
  • Open the project in VS Code
  • Open Continue chat (sidebar) and ask:
    • "Create a complete Blog system with:
- Posts, Categories, Tags (many-to-many)
- User roles: admin, author, subscriber
- CRUD for posts with image upload
- Category and tag filtering
- Pagination, search
- Vue.js frontend with Inertia
Write all migrations, models, controllers, requests, policies,
notifications, routes, and the Vue components."

    The AI will generate each file. Click "Add to file" or "Create new file" for each response. You can also ask it to generate files one at a time for more control.

    Best practice: For large projects, break it down:
    1. "Create the migrations for posts, categories, and tags"
    2. "Create the Eloquent models with relationships"
    3. "Create the PostController with CRUD methods"
    ... and so on. The AI maintains context across your conversation.

    Generate Individual Features

    Common Laravel features you can generate with one prompt:

    Authentication + Breeze
    REST API with Sanctum
    Admin panel with Filament
    Payment integration
    Email notifications
    Queue jobs + batches

    Step 7: End-to-End Workflow

    Here's a real workflow: Building an API-driven task manager with Vue. Follow along with Continue.dev chat and autocomplete.

    1 Setup project 
    composer create-project laravel/laravel taskmanager
cd taskmanager
php artisan install:api

    Then ask Continue: "Create a Task model with title, description, status, priority, due_date, and user_id foreign key"

    2 Build API

    Ask Continue one by one:

    • "Create a TaskController with index, store, show, update, destroy"
    • "Add form requests for Task store and update with validation"
    • "Create a TaskResource for API responses"
    • "Create a Policy so users can only see their own tasks"
    • "Add API routes for tasks with auth:sanctum middleware"

    The AI generates each file. Accept and save.

    3 Vue Frontend 
    php artisan install:api --with-frontend
npm install
# or manually: composer require laravel/breeze --dev
# php artisan breeze:install vue

    Then ask: "Create a Vue 3 TaskList component that fetches tasks from /api/tasks and displays them in a table with status badges"

    Continue will generate the Vue SFC with Composition API.

    4 Polish with AI
    • "Add pagination to the Task index and a loading spinner"
    • "Add sort by priority and filter by status in the API"
    • "Write tests for the Task API endpoint"
    • "Add a notification when a task is completed"
    Throughout this process, autocomplete suggests code as you type. The chat helps you plan and generate larger blocks. Together they make you 2-3x faster.

    Advanced: PHP + Ollama API

    You can call Ollama directly from PHP for batch operations, automated code generation, or building AI features into your Laravel app.

    Option A: Guzzle HTTP Client

    use Illuminate\Support\Facades\Http;

$response = Http::withOptions(['base_uri' => 'http://localhost:11434'])
  ->post('/api/generate', [
    'model'  => 'deepseek-coder:6.7b',
    'prompt' => 'Write a Laravel scope for active users',
    'stream' => false,
  ]);

$data = $response->json();
echo $data['response']; // "public function scopeActive..."

    Option B: OpenAI-Compatible Client

    Ollama exposes an OpenAI-compatible API at /v1. Use the openai-php/client package:

    composer require openai-php/client
    $client = OpenAI::factory()
  ->withApiKey('unused') // Ollama ignores the key
  ->withBaseUri('http://localhost:11434/v1')
  ->make();

$result = $client->chat()->create([
  'model'    => 'deepseek-coder:6.7b',
  'messages' => [
    ['role' => 'user', 'content' => 'Create a Laravel validation rule for phone numbers'],
  ],
]);

echo $result->choices[0]->message->content;

    Option C: Artisan Command

    php artisan make:command GenerateFromAI
    // app/Console/Commands/GenerateFromAI.php
public function handle()
{
    $prompt = $this->ask('What should I generate?');
    $model = $this->choice('Model', ['deepseek-coder:6.7b', 'codegemma:7b'], 0);

    $response = Http::post('http://localhost:11434/api/generate', [
        'model'  => $model,
        'prompt' => $prompt,
        'stream' => false,
    ]);

    $code = $response->json()['response'];

    $path = $this->ask('Save to which file?', 'generated.txt');
    File::put(base_path($path), $code);
    $this->info("Saved to $path");
}
    Real use case: Build a Laravel command that reads your migration files, sends them to Ollama with a prompt like "Generate model + controller + resource for this schema", and creates all files automatically. One command = full CRUD scaffold.

    Troubleshooting

    Problem Solution
    Autocomplete too slow Use a smaller model (CodeGemma 2B).
    Close unused files to reduce context.
    Set "contextLength": 1024 in config.
    Enable GPU in Ollama: settings → system tray → "Use GPU".
    Model won't download Check disk space. Run ollama list to see what's installed.
    Try a smaller model first: ollama pull phi3:mini.
    Restart Ollama from system tray.
    Continue can't connect Ensure Ollama is running (system tray icon).
    Check http://localhost:11434 in browser — should show "Ollama is running".
    Verify provider is set to "ollama" in config.json.
    Restart VS Code.
    High RAM / CPU usage Close other heavy apps. Use a smaller model.
    In Ollama settings → limit threads: 4.
    Restart Ollama after heavy usage to free memory.
    Poor quality code Switch to a better model (DeepSeek-Coder 6.7B).
    Provide more context in your prompt.
    Include open files with relevant code.
    Be specific: "Write a Laravel 13 controller using invokable pattern".
    GPU not being used Install NVIDIA CUDA.
    Check Ollama logs: right-click system tray → View Logs.
    On laptops, ensure Ollama uses your dedicated GPU (Windows Graphics Settings).
