Bootstrap

Complete Guide & Reference v5.3.x CSS + JS Mobile-First

Bootstrap is the world's most popular CSS framework for building responsive, mobile-first sites. This guide covers CDN setup, grid system, components, utilities, and dark mode (5.3) with live code examples.

CDN Setup

The fastest way to start â€” add these two lines inside <head>.

CSS (head)
<!-- Bootstrap 5.3 CSS -->
<link href="lib/bootstrap/bootstrap.min.css" rel="stylesheet">
JS (before </body>)
<!-- Bootstrap 5.3 JS Bundle (includes Popper) -->
<script src="lib/bootstrap/bootstrap.bundle.min.js"></script>
Tip: Always use the bootstrap.bundle.min.js version (includes Popper for tooltips & dropdowns). The separate bootstrap.min.js requires you to add Popper separately.

NPM / Sass Setup

For build-tool workflows (Vite, Webpack, Laravel Mix).

# Install Bootstrap & Sass
npm install bootstrap @popperjs/core sass

# Or via Yarn
yarn add bootstrap @popperjs/core sass
Import in your SCSS
// Custom variables BEFORE Bootstrap import
$primary: #6f42c1;
$border-radius: 0.5rem;

// Bootstrap
@import "bootstrap/scss/bootstrap";
Import in your JS
// Bootstrap JS
import * as bootstrap from 'bootstrap';

// Or individual components
import { Modal, Tooltip, Popover } from 'bootstrap';

Dark Mode 5.3

Bootstrap 5.3 introduced native dark mode via the data-bs-theme attribute. No extra CSS needed.

Toggle Dark Mode (HTML)
<!-- Light mode (default) -->
<html data-bs-theme="light">

<!-- Dark mode -->
<html data-bs-theme="dark">

<!-- Per-component override -->
<div data-bs-theme="dark">...
Dark Mode Toggle (JS)
// Toggle between light & dark
const root = document.documentElement;
btn.addEventListener('click', () => {
  const next = root.getAttribute('data-bs-theme') === 'dark' ? 'light' : 'dark';
  root.setAttribute('data-bs-theme', next);
  localStorage.setItem('bsTheme', next);
});
CSS Variables: In dark mode, Bootstrap switches all CSS variables. You can reference them: var(--bs-body-bg), var(--bs-body-color), var(--bs-border-color) â€” they adapt automatically.

Best Practices

Mobile-First Design

Start with the mobile layout (col-12), then add breakpoints (col-md-6). Use d-none d-md-block to show/hide.

Use CSS Variables

Override --bs-* variables instead of writing custom CSS. This keeps your theme consistent and makes dark mode work automatically.

Utility Classes Over Custom CSS

Use Bootstraps's spacing, flex, color, and text utilities instead of writing custom CSS. Less code = easier maintenance.

Dark Mode Ready

Use data-bs-theme="dark" on <html> or on specific containers. All components and utilities adapt automatically. Store user preference in localStorage.

Performance

Use loading="lazy" on images. Don't import all JS components if you only need a few â€” import individually via NPM.

Accessibility

Use semantic HTML (<nav>, <main>, <section>), add aria-label to interactive elements, and always pair form inputs with <label> tags.
