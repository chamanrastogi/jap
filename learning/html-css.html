Flexbox

Quick Reference

One-dimensional layout. Best for nav bars, centering, card rows, toolbars.

.container {
  display: flex;              /* or inline-flex */
  flex-direction: row;        /* row | row-reverse | column | column-reverse */
  flex-wrap: wrap;            /* nowrap | wrap | wrap-reverse */
  justify-content: center;    /* flex-start | flex-end | center | between | around | evenly */
  align-items: center;        /* stretch | flex-start | flex-end | center | baseline */
  align-content: center;      /* (multi-line only) */
  gap: 1rem;                  /* row-gap + column-gap shorthand */
}

.item {
  flex: 1 1 0%;              /* grow | shrink | basis */
  align-self: center;         /* override alignment */
  order: -1;                  /* reorder visually */
gap on flexbox is fully supported in all modern browsers. No more margin hacks on children.

Grid & Subgrid

Grid Reference
.container {
  display: grid;
  grid-template-columns: repeat(3, 1fr);    /* 3 equal cols */
  grid-template-rows: auto 1fr auto;         /* header / main / footer */
  gap: 1.5rem;
  grid-template-areas:
    "header header header"
    "sidebar main   main"
    "footer footer footer";
}

.item-header { grid-area: header; }
.item-sidebar { grid-area: sidebar; }

.item:nth-child(2) {
  grid-column: 2 / 4;      /* span across */
  grid-row: 1 / 3;
}
Subgrid â€” inherits track sizing from parent grid: 
.parent {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
}
.child {
  display: grid;
  grid-column: 1 / -1;
  grid-template-columns: subgrid;  /* matches parent tracks */
  /* child's columns now align with parent */
}

Useful for aligning cards in a grid where each card has a different content height.

Container Queries

Component-Level Responsiveness

The biggest CSS game-changer since Flexbox. Respond to the parent container's size, not the viewport.

/* 1. Define a containment context */
.card-wrapper {
  container-type: inline-size;
  container-name: card;
}

/* 2. Query the container */
@container card (min-width: 400px) {
  .card {
    display: grid;
    grid-template-columns: 200px 1fr;
  }
}

@container card (max-width: 399px) {
  .card {
    display: flex;
    flex-direction: column;
  }
}

/* Container query units */
.cqw  /* 1% of container width */
.cqh  /* 1% of container height */
.cqi  /* 1% of container inline size */
.cqb  /* 1% of container block size */
.cqmin / .cqmax  /* smaller/larger of cqi/cqb */

Modern Selectors

:has() â€” The Parent Selector
/* Select a card that CONTAINS an image */
.card:has(img) {
  grid-template-rows: 200px 1fr;
}

/* Style a form group that has an error */
.form-group:has(.error) label {
  color: red;
}

/* Previous sibling! (h2 that comes before p) */
h2:has(+ p) {
  margin-bottom: 0;
}

/* All modern browsers support :has() */
/* Chain it: :has(:has(...)) works too */
Game changer: :has() finally lets us select a parent based on its children. Also enables previous-sibling selectors. Supported in all major browsers since early 2024.
:where(), :is(), :not()
/* :where() â€” zero specificity (great for resets) */
:where(h1, h2, h3) { margin: 0; }     /* specificity = 0 */
h1 { margin: 1rem; }                   /* wins (specificity = 0,0,1) */

/* :is() â€” same as :where() but keeps specificity */
:is(h1, h2, h3) { color: blue; }      /* specificity = 0,0,1 */

/* :not() now supports selector lists */
:not(.error, .warning, .disabled) { opacity: 1; }

/* Combo â€” style cards that have images AND are not disabled */
.card:has(img):not(.disabled) {
  opacity: 1;
}

Layers & Nesting

@layer â€” Cascade Control

Control the cascade explicitly â€” framework styles never override your components.

@layer reset, base, components, utilities;

@layer reset {
  *, *::before, *::after { box-sizing: border-box; margin: 0; }
}

@layer base {
  body { font-family: system-ui; line-height: 1.6; }
  a { color: blue; }
}

@layer components {
  .btn { padding: 0.5rem 1rem; border-radius: 0.25rem; }
}

@layer utilities {
  .text-center { text-align: center; }
  .mt-4 { margin-top: 1rem; }
}

/* Later layers override earlier ones â€” even with lower specificity */
@property â€” Registered Custom Properties

Define typed CSS variables for animation, fallbacks, and validation.

@property --primary-color {
  syntax: "<color>";
  inherits: true;
  initial-value: #4f46e5;
}

@property --spacing {
  syntax: "<length>";
  inherits: false;
  initial-value: 1rem;
}

/* Now you can animate custom properties! */
.card {
  --primary-color: blue;
  transition: --primary-color 0.3s;
}
.card:hover {
  --primary-color: red;
}
Without @property, CSS animations on custom properties don't work â€” the browser doesn't know the type. With @property, it can interpolate between colors/lengths/angles.

/* Balanced text wrapping (new!) */
h1, h2, h3 {

}
p {
  text-wrap: pretty;     /* avoid orphan words on last line */

@font-face {
  font-family: 'MyVariableFont';
  src: url('font.woff2') format('woff2-variations');
  font-weight: 100 900;         /* weight axis range */
  font-stretch: 75% 125%;       /* width axis range */
}
body {
  font-family: 'MyVariableFont', sans-serif;
  font-weight: 400;             /* or 372 â€” any value in range */
}
text-wrap: balance â€” single line of CSS and your headings look like a designer typeset them. pretty prevents orphans. Both are supported in Chrome 117+, Safari 17.5+, Firefox 121+.

Colors & Gradients

Modern Color Spaces
/* OKLCH â€” perceptually uniform, wider gamut */
.primary {
  background: oklch(0.6 0.2 280);   /* lightness, chroma, hue */
}
.oklch-example {
  color: oklch(0.4 0.15 200);       /* dark cyan */
}

/* color-mix() â€” blend two colors */
.mixed {
  background: color-mix(in oklch, red 40%, blue 60%);
}
.hover-effect {
  background: color-mix(in srgb, var(--primary), white 30%);
}

/* Relative colors (modify an existing color) */
.lighter {
  --primary: #4f46e5;
  background: oklch(from var(--primary) l c h / 0.5);
  /* Keep hue/chroma, change alpha */
}

/* P3 wide gamut (brighter displays) */
@media (color-gamut: p3) {
  .vibrant {
    color: color(display-p3 0 0.8 0.6);
  }
}

/* accent-color for form controls */
input[type="checkbox"] {
  accent-color: var(--coral);
}
OKLCH is the color space of the future â€” perceptually uniform, works like HSL but actually looks right. color-mix() replaces preprocessor darken/lighten. Supported in all modern browsers.

Animation & Transitions

View Transitions API
/* SPA-like page transitions with one line */
@view-transition {
  navigation: auto;
}

/* Or manual for specific transitions */
document.startViewTransition(() => {
  updateDOM();
});

/* Style individual transition elements */
::view-transition-old(page) {
  animation: fade-out 0.3s;
}
::view-transition-new(page) {
  animation: fade-in 0.3s;
}

/* Cross-fade between elements with the same view-transition-name */
.thumbnail {
  view-transition-name: gallery-image;
}
.lightbox {
  view-transition-name: gallery-image;
}
View Transitions API â€” smooth animations between DOM states. The browser handles the complexity. Supported in Chrome 111+, Safari 18+, and coming to Firefox.
Scroll-Driven Animations
/* Animate based on scroll position â€” no JS intersection observer */
@keyframes fade-in {
  from { opacity: 0; scale: 0.8; }
  to { opacity: 1; scale: 1; }
}

.card {
  animation: fade-in linear;
  animation-timeline: view();        /* triggers based on element visibility */
  animation-range: entry 0% entry 100%;  /* animate during entry */
}

/* Progress indicator linked to scroll */
@keyframes shrink-header {
  from { height: 120px; font-size: 2rem; }
  to { height: 60px; font-size: 1rem; }
}

header {
  animation: shrink-header linear;
  animation-timeline: scroll();
  position: sticky;
  top: 0;
}

/* @starting-style â€” animate elements entering the DOM */
@starting-style {
  .toast {
    opacity: 0;
    translate: 0 100%;
  }
}
.toast {
  opacity: 1;
  translate: 0 0;
  transition: opacity 0.3s, translate 0.3s;
}

/* overlay + allow-discrete for entry/exit */
.modal {
  overlay: auto;
  transition: opacity 0.3s, overlay 0.3s allow-discrete;
}
@starting-style {
  .modal { opacity: 0; }
}
Scroll-driven animations are the future of scroll-based effects. @starting-style solves the "can't animate on mount" problem. transition-behavior: allow-discrete enables animation of discrete properties like overlay and display.

A11y Checklist
  • Every <img> needs alt (even alt="" for decorative)
  • Color contrast â€” 4.5:1 for text, 3:1 for large text (18px+)
  • Focus indicators â€” never outline: none without replacement
  • Labels on form inputs â€” use <label> or aria-label
  • Heading hierarchy â€” h1 â†’ h2 â†’ h3 (never skip levels)
  • aria-expanded on expandable elements (accordions, menus)
  • aria-current="page" on current nav item
  • role="button" on clickable divs (better: use <button>)
  • Focus management â€” trap focus in modals, return on close
  • Reduce motion â€” respect prefers-reduced-motion
